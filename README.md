# InsightFlow X

Agentic Organizational Intelligence Platform

InsightFlow X transforms fragmented organizational knowledge into actionable intelligence using Retrieval-Augmented Generation (RAG), semantic search, AI agents, and decision intelligence.

## Problem

Organizations generate vast amounts of knowledge through:

* Customer interviews
* Support tickets
* Surveys
* Internal reports
* Meeting transcripts

Most of this knowledge remains fragmented and underutilized.

## Solution

InsightFlow X enables organizations to:

* Discover hidden insights
* Detect emerging trends
* Analyze organizational memory
* Generate evidence-based recommendations
* Support strategic decision making

## Tech Stack

* Python
* Gemini API
* ChromaDB
* LangChain
* Streamlit
* Plotly

## Features

* Semantic Knowledge Retrieval
* RAG-Based Question Answering
* Theme Discovery Agent
* Trend Detection Agent
* Decision Intelligence Agent
* Evaluation Dashboard

## Architecture

Documents → Embeddings → ChromaDB → Retrieval → Agents → Insights → Dashboard
